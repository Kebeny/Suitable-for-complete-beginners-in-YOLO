# 使用说明

本文档介绍 YOLO 训练引导工具的完整使用流程。

## 一、安装

### 方式一：使用安装包（推荐普通用户）

1. 双击 `YOLO训练引导工具_Setup.exe`
2. 选择安装路径（默认 `C:\Program Files (x86)\YOLO训练引导工具`）
3. 勾选“创建桌面快捷方式”（推荐）
4. 点击安装，完成后双击桌面图标启动

首次启动可能需要 10~20 秒，请耐心等待。

### 方式二：从源码运行（开发者）

```bash
conda create -n ytg_env python=3.12 -y
conda activate ytg_env
pip install -r requirements-gpu.txt   # 有 NVIDIA 显卡
# 或
pip install -r requirements-cpu.txt   # 无显卡
python src/main.py
```

## 二、流程一：数据集生成

流程一负责准备 YOLO 训练所需的数据集，有两种模式。

### 模式 A：导入原始图片，生成新数据集

**步骤 1：选择模式**

点击“导入原始图片、生成新数据集”。

**步骤 2：导入图片并设置类别**

- 点击“选择图片文件夹”，导入原始图片
- 在输入框中填写类别名称，每行一个，例如：

  ```text
  cylinder
  triangular prism
  cube
  small red cube
  ```

- 点击“确认类别”

**步骤 3：图像标注**

- 在左侧图片列表选择一张图片
- 在预览区按住鼠标左键拖拽画框，松开完成
- 画框后选择该框对应的类别
- 工具栏可切换上一张 / 下一张
- 建议先选类别再画框，也可以先画框再选类别

**步骤 4：生成数据集**

- 设置训练集 / 验证集比例（默认 8:2）
- 选择输出目录（默认 `datasets/project/`）
- 点击“生成数据集”
- 完成后可跳转到流程二

### 模式 B：导入已有 YOLO 数据集

**步骤 1：选择模式**

点击“导入已有数据集”。

**步骤 2：查看格式要求并选择数据集**

标准 YOLO 数据集目录结构：

```text
dataset/
├── data.yaml
├── images/
│   ├── train/
│   └── val/
└── labels/
    ├── train/
    └── val/
```

- 点击“选择数据集目录”
- 程序会自动校验目录结构和 `data.yaml`
- 校验通过后显示类别数、训练集 / 验证集数量
- 校验不通过会提示重新构建数据集

## 三、流程二：YOLO 训练

### 步骤 1：硬件检测与参数设置

- 点击“检测硬件”，自动识别 GPU / CPU
- 显示 GPU 型号、显存、PyTorch 与 CUDA 版本
- 根据显存推荐轮次、批次、图片尺寸
- 选择数据集后，会再根据数据量调整轮次
- 所有参数都可以手动修改

### 步骤 2：选择模型

从下拉列表选择预训练模型，默认 `yolo11n.pt`。

| 模型 | 说明 |
|------|------|
| yolo11n | 超轻量，速度快 |
| yolo11s | 轻量 |
| yolo11m | 均衡 |
| yolo11l | 高精度 |
| yolo11x | 最高精度，显存要求高 |
| yolo26n | 新系列轻量模型 |
| yolov8 系列 | 经典系列模型 |

### 步骤 3：选择数据集

- 下拉框会自动列出 `datasets/` 下的数据集
- 也可以点击“浏览”选择其他目录

### 步骤 4：开始训练

- 点击“开始训练”
- 实时日志与 Ultralytics 终端输出一致
- 训练中可以点击“停止训练”
- 训练完成后自动进入结果展示

### 步骤 5：查看训练结果

- 展示训练曲线、混淆矩阵、PR 曲线等
- 双击图片可放大查看
- 权重保存在 `runs/train/` 下
- 点击“打开权重文件夹”可直接查看

### 训练参数说明

| 参数 | 说明 |
|------|------|
| 轮次（epochs） | 训练完整过数据集的次数，数据量大时自动增加 |
| 批次（batch） | 每次处理的图片数，显存越大可设越大 |
| 图片尺寸（imgsz） | 输入图片大小，默认 640 |
| 早停（patience） | 验证集效果不再提升时自动停止 |
| 数据增强 | 随机变换以提升模型泛化能力 |

## 四、流程三：YOLO 识别

### 模型选择

- 列表显示预训练模型 + 最新训练结果 `best.pt`
- 训练完成后点击“刷新”可看到最新模型
- 支持浏览其他 `.pt` 文件

### 设备选择

| 选项 | 说明 |
|------|------|
| 自动 | 有 GPU 用 GPU，无 GPU 用 CPU |
| CPU | 强制使用 CPU，速度较慢 |
| GPU (CUDA) | 强制使用 GPU |

### 检测参数

- 置信度阈值：默认 0.4
  - 调低 = 检测框更多，可能误检
  - 调高 = 检测框更少，可能漏检

### 模式一：摄像头实时识别

1. 选择“摄像头实时识别”
2. 在下拉框选择摄像头设备
3. 点击“开始识别”
4. 预览区实时显示检测画面
5. 点击“停止识别”结束

### 模式二：文件夹批量识别

1. 选择“文件夹批量识别”
2. 点击“开始识别”
3. 选择图片文件夹
4. 预览区依次显示每张图片的识别结果
5. 结果自动保存到 `runs/predict/时间戳/`
6. 完成后弹出提示

### 摄像头选择

- 笔记本自带摄像头默认排第一位
- USB / 网络摄像头显示为“未知摄像头”或产品型号
- 点击“刷新”重新扫描
