# 打包说明

本文档介绍如何把项目打包为 Windows exe 和安装包。

## 一、准备工作

- Windows 10 / 11 64 位
- Python 3.12（推荐使用项目自带环境）
- 已安装项目依赖：`pip install -r requirements-gpu.txt`
- 已安装 PyInstaller：`pip install pyinstaller==6.21.0`
- 已安装 Inno Setup 6：https://jrsoftware.org/isdl.php

打包前确认以下目录存在：

```text
models/          # 至少包含一个 .pt 模型
fonts/           # 内置字体
runtime/         # Windows MSVC 运行库
runtime_hooks/   # PyInstaller 运行时钩子
```

## 二、打包 exe

在项目根目录执行：

```bash
python -m PyInstaller --clean --noconfirm YOLO训练引导工具.spec
```

也可以直接双击：

```text
build_exe.bat
```

输出目录：

```text
dist/YOLO训练引导工具/
├── YOLO训练引导工具.exe
└── _internal/
    ├── models/
    ├── torch/
    ├── runtime/
    └── ...
```

## 三、生成安装包

确认 `setup.iss` 中的 `Source` 指向：

```ini
Source: "dist\YOLO训练引导工具\*"; DestDir: "{app}"; Flags: ignoreversion recursesubdirs createallsubdirs
```

然后执行：

```text
build_installer.bat
```

或手动执行：

```bat
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" setup.iss
```

输出：

```text
YOLO训练引导工具_Setup.exe
```

## 四、重要说明：WinError 1114 / c10.dll 修复

PyInstaller 的 `pyi_rth_pyqt5` 运行时钩子会在用户脚本执行前导入 `PyQt5.QtCore`，从而优先加载 PyQt5 自带的旧版 `MSVCP140.dll`。之后 torch 加载 `c10.dll` 时，会因 MSVC 运行库版本冲突报：

```text
OSError: [WinError 1114] 动态链接库(DLL)初始化例程失败。
Error loading "...\_internal\torch\lib\c10.dll" or one of its dependencies.
```

本项目通过 `runtime_hooks/pyi_rth_000_preload_msvc.py` 解决：

- 钩子文件名以 `pyi_rth_000_` 开头，排序在 `pyi_rth_pyqt5` 之前
- 在 PyQt5 加载旧运行库之前，先加载 `runtime/` 下的 14.44 版 MSVC 运行库
- `YOLO训练引导工具.spec` 中已通过 `runtime_hooks` 引入该钩子

> 不要手动把 `c10.dll` 加进 `binaries` 预加载，也不要往 `torch/lib` 里乱塞系统 DLL，容易导致界面卡死或新的冲突。

## 五、体积说明

打包后体积较大：

- `dist/YOLO训练引导工具/`：约 5GB
- `YOLO训练引导工具_Setup.exe`：约 3GB

主要来自 PyTorch、CUDA、cuDNN 运行库。保持默认即可，不要尝试删除 `torch/lib` 下的 DLL。

## 六、常见问题

**Q：打包后启动报缺字体？**  
A：确认 `fonts/msyh.ttc` 存在；程序找不到时会自动回退到系统字体。

**Q：打包后 GPU 检测报 c10.dll 错误？**  
A：确认 `runtime_hooks/pyi_rth_000_preload_msvc.py` 已存在，且 spec 中 `runtime_hooks` 已引用它，然后重新打包。

**Q：安装到别的电脑后提示找不到模型？**  
A：安装包已内置 `models/`，如果安装后没有，检查打包前 `models/` 是否有文件。
